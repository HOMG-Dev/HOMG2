# C3 独立退出计划

C1 合入后，从最新 `origin/main` 建 `codex/m1-c3`。可与 C2 并行推进。[C3 #17](https://github.com/HOMG-Dev/HOMG2/issues/17)

## 实施

1. 把 C1 的退出回调接到引擎的 `Quit Game`，使用菜单本地玩家上下文。鼠标和键盘走同一回调。
2. 记录退出调用及独立进程的验证方式。若通过 PIE 冒烟，先记录该次测试的运行模式，再单独验证真实的独立进程退出。

## 独立子代理验收

1. 编辑器保持打开，启动 Standalone 游戏，记录编辑器和游戏的进程 ID。点击「退出」并确认游戏进程结束、编辑器进程仍在运行。
2. 再启动一次，使用 Tab 聚焦退出并用 Enter 激活，复核同样的结果。保留两个进程的验证记录和相关日志。
