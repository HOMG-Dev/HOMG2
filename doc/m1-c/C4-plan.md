# C4 返回与重复开局计划

C2 和 E2 合入后，从最新 `origin/main` 建 `codex/m1-c4`。使用 E2 的 HUD 生命周期和 D1 的本局会话。实现基于[游戏策划案](../游戏策划案.md)第 2.1 节的开局流程，首轮金币和部署状态由会话初始化。[C4 #18](https://github.com/HOMG-Dev/HOMG2/issues/18) · [E2 #23](https://github.com/HOMG-Dev/HOMG2/issues/23) · [D1 #19](https://github.com/HOMG-Dev/HOMG2/issues/19)

## 实施

1. 由战场本地 PlayerController 处理 Esc。打开一个可聚焦的简易面板，提供「继续」「返回主菜单」，面板获得焦点并拦截镜头和地图输入。继续后恢复战场输入，保留当前轮次、阶段、金币、选择和装备状态。
2. 返回动作设置一次性保护并旅行回 `L_M1_Menu`。在关卡退出的生命周期中清理菜单和 HUD、会话订阅、局内选择、战场输入映射、计时器与委托。复用 E2 的解绑与 D1 的会话销毁入口，确保退出清理可重复调用。
3. 再次进局时由战场创建新的会话、HUD 和输入绑定。测试金币、库存、营与轮次从同一份夹具初值恢复，状态推进仍由 D1 及其后续会话逻辑负责。

## 独立子代理验收

1. 进局后修改一个可操作的会话值或选择，再打开 Esc 面板。确认面板可操作且点击不落到战场，选择「继续」后轮次和已改状态保持，镜头与 HUD 恢复输入。
2. 执行「返回主菜单 → 开始游戏」两次。每次都核对首轮部署、初始金币和库存、默认选择、一个 HUD 实例和一套生效的输入绑定。用一次可观察的会话变更确认 HUD 只刷新一次。
3. 留存两次开局的日志、截图和旧会话解绑证据。确认返回后的菜单仍可正常使用键鼠和退出。
