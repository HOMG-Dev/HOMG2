# C2 开始进局计划

C1 和 B1 合入后，从最新 `origin/main` 建 `codex/m1-c2`。战场目标使用 B1 的 `L_M1_Field` 资产路径。[C2 #16](https://github.com/HOMG-Dev/HOMG2/issues/16) · [B1 #12](https://github.com/HOMG-Dev/HOMG2/issues/12)

## 实施

1. 把 C1 的开始回调接到本地地图旅行。用明确的地图引用指向 B1 的灰盒战场，使用 M1 的默认测试配置开局。入口直接进入战场。
2. 接受开始动作后立即设置一次性保护并禁用按钮，鼠标和键盘走同一个回调。地图无法加载时恢复按钮和焦点，并给出失败提示或诊断日志。
3. 离开菜单时清理菜单 Widget。进入战场后由关卡使用的本地控制器恢复战场输入模式与焦点；复用 B1 的关卡和已有控制器接口，与 B2 的镜头接入约定保持一致。

## 独立子代理验收

1. 从 Standalone 菜单快速连点、再以连续键盘输入进行另一轮测试。每次只接受一次旅行，地图加载日志中只有一次 `L_M1_Field` 进入记录。
2. 进入灰盒战场后确认菜单消失，战场收到输入，焦点没有停在旧按钮。可用 PIE 冒烟并以 Standalone 复核。使用测试副本模拟失效地图引用时，确认可以重试。
